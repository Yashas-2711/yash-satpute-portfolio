# Yash Ankush Satpute - Personal Portfolio Website

A modern, professional, responsive personal portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## 📋 Overview

This portfolio website showcases the skills, projects, and experience of Yash Ankush Satpute, a Third-Year Artificial Intelligence & Data Science engineering student focused on developing AI-driven web applications and integrating Generative AI APIs into modern software systems.

The website is designed to be clean, professional, and suitable for AI Developer / Full-Stack Developer internship applications.

## 🎨 Design Features

- **Dark Professional Theme**: Deep navy/charcoal background with electric blue/teal accents
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI Elements**: Rounded cards, subtle shadows, clean spacing
- **Smooth Animations**: Fade-in, slide-up, and hover effects (respects `prefers-reduced-motion`)
- **Accessible Design**: Semantic HTML, proper labels, keyboard navigation
- **CSS Variables**: For easy theme customization

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling with Flexbox, Grid, and custom properties
- **Vanilla JavaScript** - DOM manipulation, form validation, and interactivity
- **No Frameworks**: Pure HTML/CSS/JS implementation

## 🔧 Setup & Usage

1. Clone or download the repository
2. Replace `assets/profile.jpg` with your actual profile photo
3. Add project screenshots to `assets/project-images/` if desired
4. Open `index.html` in your preferred web browser
5. No build process or dependencies required

## 📱 Responsiveness

The website adapts to various screen sizes:
- **Desktop (>1024px)**: Multi-column layouts
- **Tablet (768-1024px)**: Adjusted spacing and stacked elements
- **Mobile (<768px)**: Single-column layout, hamburger menu, touch-friendly controls

## 🎯 Customization

To personalize this portfolio:

1. **Update Content**: Modify text in `index.html` for your information
2. **Change Colors**: Edit CSS variables in `:root` section of `style.css`
3. **Add Real Image**: Replace `assets/profile.jpg` with your actual photo
4. **Update Links**: Replace GitHub, LinkedIn, and project URLs with your own
5. **Add Projects**: Duplicate project cards in the projects section and update content
